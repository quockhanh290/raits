Bootstrap — NORMALIZED (R-multiple) vs DOLLAR per-trade P&L
Baseline : is_baseline_cb_fixed_2026-07-08.csv  (605 trades, continuous IS 2017-2022)
N_BOOT=10000  seed=42
R-multiple = net_pnl / (shares * |entry_price - stop|)
H0: mean(R) <= 0  |  same threshold as dollar bootstrap

STEP 1 — METHODOLOGY DIAGNOSIS
------------------------------------------------------------
Dollar bootstrap problem: Kelly=0.75 + compounding -> position size scales with
equity at each trade. Dollar P&L from different equity levels is NOT homogeneous.
A trade at $60k equity has ~20% larger positions than the same trade at $50k.
Bootstrapping raw dollar P&L treats these as comparable — they are not.

R-multiple fix: initial_risk = shares * |entry_price - stop| is set at entry
and reflects the actual dollar at risk regardless of equity level.
R = net_pnl / initial_risk is scale-independent — the same entry/exit logic
produces the same R regardless of position size or account equity.

STEP 4 — WHAT EACH TEST ANSWERS
------------------------------------------------------------
  R-multiple bootstrap (this script):
    H0: mean(R) <= 0  -> 'Does the strategy generate positive expected
    value per unit of risk, independent of position size and compounding?'
    This is the correct test for EDGE — scale-independent, path-independent.

  Dollar bootstrap (bootstrap_continuous.py):
    H0: mean(dollar_pnl) <= 0  -> conflates edge with compounding scale.
    Trades at higher equity (larger positions) have disproportionate weight.
    Underestimates edge if strategy performs better early (low-equity phase);
    overestimates if strategy performs better late (high-equity phase).
    NOT the right test for 'does the strategy have edge.'

  Equity-curve metrics (Calmar, Sharpe):
    DO correctly account for compounding and path dependency.
    Right for 'how much does the compounded system earn?' — not per-trade.
